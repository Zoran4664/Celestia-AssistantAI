> 本说明书面向普通用户（小白友好），介绍 V2 新增功能的**用法**。

## 一、记忆更聪明

### 1.1 固定记忆（永远记住的事）
有些事不希望被遗忘（比如你的生日、称呼、喜好）。
- **在哪里设置**：主界面 → 设置 → 记忆 →「固定记忆（每行一条，自动脱敏）」
- **怎么用**：每行写一条，点「保存固定记忆」。保存后，角色对话时**始终带着这些内容**，不受记忆检索影响。
- 也可以直接编辑 `data/pinned.md` 文件（每行一条，`#` 开头的是注释）。

### 1.2 记忆传送带（角色记得「今天聊过什么」）
每次对话后，程序会自动把今天的对话压缩成摘要，存在 `history/memory_compile/daily/`。
对话时角色会看到「今天的对话 + 最近几天」的摘要，让陪伴更有连续性。
- **无需设置**：自动工作（依赖小模型，失败静默降级，不影响对话）。

### 1.3 记忆整合（Memory Dream）
长期记忆碎片太多时，可以主动整理：
- 设置 → 记忆 →「执行记忆整合（Dream）」→ 确认后后台执行。
- 它会合并重复/相关的记忆、删除冗余，**执行前自动备份快照，可回滚**。
- 默认关闭自动周期；可在 `data/config.json` 的 `dream.enabled=true` 开启每日自动整合。

### 1.4 角色自动写日记
开启后，每天固定时间让当前角色把当天聊的内容写成一篇第一人称日记。
- **开启**：设置 → 记忆（或修改 `data/config.json`）：
  ```json
  "ui": { "auto_diary_enabled": true, "auto_diary_time": "23:00" }
  ```
- 日记保存在 `dailydata/auto_diary/YYYY-MM-DD.md`（正文 + 备忘清单）。
- 原有手动日记功能不变。

## 二、桌宠更主动

### 2.1 心跳巡检（工作区变化 → 桌宠主动关怀）
桌宠会定期检查数据目录有没有新文件/变化，发现后以角色语气主动说一句。
- **开启**：设置 → 桌面形象 →「主动关怀开关」勾选，可调「关怀间隔(分钟)」。
- 每天最多主动几次（默认 6 次，防打扰），记录在 `data/heartbeat_state.json`。
- 关闭开关即可暂停，不删除任何数据。

### 2.2 通用定时任务（Cron 引擎）
问候、夜间提醒、记忆清理等定时器已统一为通用定时引擎（`data/cron_jobs.json`）。
- 普通用户无需操作：现有定时行为保持不变。
- 高级用户可手动编辑 `data/cron_jobs.json` 增加任务（格式：`at` 一次性 / `every` 间隔毫秒 / `cron` 5 字段表达式）。
- 运行历史在 `data/cron_runs/`。

### 2.3 日程 / 提醒（新增确认步骤）
桌宠右键 → 添加日程 / 提醒：填完信息后会先弹出**确认框**，确认后才真正添加（防止误触）。

## 三、历史会话更好用

### 3.1 搜索历史
历史侧栏顶部有搜索框：输入关键词即搜（先匹配标题，再搜正文），点击结果跳转。

### 3.2 置顶 / 归档
- 右键某条历史 →「置顶」：固定在列表最上方（再点一次取消置顶）。
- 右键 →「归档此会话」：移出主列表（文件不删除）。
- 「归档」按钮 → 归档管理：恢复 / 删除 / 清理 30 天 / 清理 90 天。

### 3.3 引用对话（引用原文继续问）
聊天区选中某条消息的文字 → 右键 →「引用到对话」：选中文字会插入输入框，继续追问时保留原文语境。

### 3.4 会话内查找（Ctrl+F）
在输入框按 `Ctrl+F` 呼出查找条：输入关键词回车定位下一条，↑/↓ 切换，Esc 关闭。

## 四、图片全屏查看

聊天里的图片（生图结果、图片附件）点击后不再直接打开系统看图，而是**全屏暗色查看器**：
- 滚轮缩放、按住拖拽平移、双击还原；
- ← / → 切换同会话相邻图片；+ / − / 0 缩放；Esc 关闭。

## 五、技能与角色生态

### 5.1 技能是什么（回顾）
输入框输入 `\@触发词` 唤起技能，例如：
- `\@translate 你好` → 翻译
- `\@research 量子计算` → 科研模式
- `\@thinking`（开关）+ `\@network`（开关）可组合

技能字段（技能库 `skills/tools_list.json` + `skilltools_information.json`）：
| 字段 | 含义 |
|------|------|
| `name` | 技能名（唯一） |
| `trigger` | `\@触发词`（唯一，不含空格） |
| `kind` | `skill`=普通技能；`switch`=可同时开 0-2 个的开关 |
| `aliases` | 别名（`\@别名` 也能唤起） |
| `category` | 分类（工具 / 记忆 / 创作 / 开关…） |
| `enabled` | 是否启用 |
| `description` | 注入 LLM 的技能说明 |
| `prompt_template` | 执行要求（可含 `{参数名}` 占位） |
| `parameters` | 参数（名称 / 默认值 / 必填） |
| `permission` | 权限档：`read`(默认) / `routine` / `review`(高风险，发送前需确认) |

### 5.2 技能包（成组管理 / 分享）
设置 → 角色卡与技能包 →「技能包管理…」：
- **新建**：起个名字（如「写作工具包」）→ 勾选要包含的技能 → 确定。
- **成组开关**：选中一个包 →「启用全部 / 停用全部」一键开关包内技能。
- **打包 zip**：把整包技能打成 zip 文件（先弹保存路径）分享给其它用户。
- **导入 zip**：选择别人给的技能包 zip，自动并入技能库（同名技能跳过，不覆盖）。

### 5.3 角色卡打包（角色迁移 / 分享 / 备份）
设置 → 角色卡与技能包：
- **导出当前角色卡**：选择保存路径 → 把当前角色的角色卡、情绪映射、立绘、桌宠动图打包成 zip。
- **导入角色卡**：选 zip → 预览角色信息 → 确认 → 自动创建角色（同名角色已存在则跳过）。导入后重启应用即可在左栏选择。

### 5.4 安装技能包 zip（带安全审查）
设置 → 角色卡与技能包 →「安装技能包 zip…」：
- 选择 zip → 自动审查包内技能风险（低 / 中 / 高）。
- 高风险技能（检测到越权 / 注入 / 诱导泄漏密钥）会弹红色确认框，**需你明确同意才安装**。
- 安装后立即生效（技能热加载）。

### 5.5 评测技能（检验技能好不好用）
设置 → 角色卡与技能包 →「评测技能…」：
- 选择技能 →「运行评测」→ 跑该技能的测试用例（`skills/test_cases/<技能名>.json`）。
- 报告显示：用例数、通过率、失败明细（触发解析 / 回复关键词）。
- 没有用例时按报告里的格式添加用例即可。

### 5.6 技能热加载
直接编辑 `skills/*.json` 保存后，**无需重启**，约 1 秒自动生效。

## 六、文件工具（读写本机文件）

让角色能帮你读 / 写 / 改本机文件。**安全保护**：只能操作项目数据目录白名单
（`data/`、`dailydata/`、`createimage/`），`config.json` 等敏感文件永远禁止。

用法（在输入框发送）：
- `\@read 路径` → 读取文件内容（支持 txt/md/docx/xlsx/pdf，中文编码自动识别）
- `\@write 路径 内容` → 把内容写入文件（发送前会弹确认框，因为属于高风险操作）
- `\@edit 路径 旧文本|新文本` → 替换文件中的文字（同样弹确认框）

示例：
```
\@write data/笔记.txt 今天学会了 V2 的文件工具
\@read data/笔记.txt
\@edit data/笔记.txt 今天|昨天
```

**写前自动备份**：每次写 / 改都会在 `history/file_history/` 存一份快照，可回滚历史版本。
路径用相对路径时基于项目根目录解析（`data/xxx` = 项目根下的 `data/xxx`），
也支持完整绝对路径（限白名单目录内）。

## 七、联网搜索增强

`\@network` 搜索现在支持**多引擎自动切换**：主引擎失败会自动换到下一个，提高成功率。
- 默认仍用原配置的引擎（`data/config.json` 的 `web.search_base` / `web.search_key`）。
- 高级：可配多个备用引擎：
  ```json
  "web": { "search_providers": [
    { "name": "备用引擎A", "base": "https://...", "key": "..." }
  ] }
  ```

## 八、常见问题

**Q1：`\@write` 提示「无权写入该路径」？**
- 确认路径在允许范围内（`data/`、`dailydata/`、`createimage/` 或项目根下）；
- 确认发送前弹的确认框点了「允许执行」；
- 相对路径基于项目根解析：`data/笔记.txt` 指项目根 `data` 目录下的文件。

**Q2：找不到 `heartbeat_state.json`？**
- 它是「主动关怀」的记录文件，**默认关闭**时不生成。在设置 → 桌面形象勾选「主动关怀开关」并重启后，文件即生成。

**Q3：导出角色卡 / 技能包时想改保存位置？**
- 已支持：点导出后会先弹出**保存路径选择框**，选好位置再导出。

**Q4：对话偶尔闪退？**
- 已修复（异步任务引用保活）。如仍遇到，把 `utils/logs/app.log` 里最近的报错发给我们。

**Q5：导入角色卡后左栏没看到新角色？**
- 导入成功后需**重启应用**（角色库在启动时扫描）。若提示「角色已存在」说明没覆盖，属正常保护。

**Q6：技能热加载没生效？**
- 确认编辑的是 `skills/tools_list.json` 或 `skills/skilltools_information.json`（UTF-8、JSON 格式正确）；约 1 秒后生效。

**Q7：固定记忆 / 记忆整合有上限吗？**
- 固定记忆按行数存储，建议控制在几十条内；记忆整合单轮最多处理 100 条碎片，可反复执行。
