# 02 · 变量与模型

## 1. 变量

| 记号 | 含义 | 维度数 | 技能内量程 |
|---|---|---|---|
| `ΣD` | 抑郁总分 | 9 | 9-45 |
| `ΣA` | 焦虑总分 | 7 | 7-35 |
| `ΣF` | 社交媒体倦怠总分 | 5 | 5-50 |
| `SS_sub` | 主观社会支持度 | 1 | 1-10，越高越好 |
| `SS_obj` | 客观社会支持度 | 1 | 1-10，越高越好 |
| `SS_uti` | 社会支持利用度 | 1 | 1-10，越高越好 |

角色：`ΣF` 为自变量，`ΣD`、`ΣA` 为因变量，`SS_sub` 为主要中介变量，`SS_obj`、`SS_uti` 为对照中介变量。

## 2. 归一化

```
Ŝ_D = (ΣD − 9) / 36          ∈ [0,1]
Ŝ_A = (ΣA − 7) / 28          ∈ [0,1]
F̂   = (ΣF − 5) / 45          ∈ [0,1]
SŜ   = (SS_sub − 1) / 9       ∈ [0,1]
Ŝ   = (Ŝ_D + Ŝ_A) / 2
```

`Ŝ` 取两项均值，`ΣD` 与 `ΣA` 的相关系数为 0.838，相加会重复计权。

## 4. 非线性函数

倦怠拐点函数：

```
Φ(x) = 0                                            x ≤ 0.40
     = 0.45 · ((x − 0.40) / 0.20)²                  0.40 < x ≤ 0.60
     = 0.45 + 0.10 · (x − 0.60) / 0.15              0.60 < x ≤ 0.75
     = 0.55 + 0.45 · ((x − 0.75) / 0.25)^1.5        0.75 < x ≤ 1.00
```

连续、单调不减，`Φ(0)=0`，`Φ(1)=1`。

支持缓冲函数：

```
Ψ(x) = x^1.5
```

两条曲线抑制低值段的过度反应，同时保留高值段的增长。

## 5. 主公式

```
IN_raw = W_SEV · Ŝ + W_F · Φ(F̂) − W_SS · Ψ(SŜ) + Trend
IN     = clamp(IN_raw, 0, 1)
```

趋势项，只计恶化：

```
Trend = min(0.10, 0.15 · max(0, Ŝ_t − Ŝ_{t−1}) + 0.10 · max(0, F̂_t − F̂_{t−1}))
```

## 6. 分档、回滞与档位下限

```
L0: IN < 0.25        L1: 0.25 ≤ IN < 0.37
L2: 0.37 ≤ IN < 0.49 L3: IN ≥ 0.49        L4: 危机覆盖
```

回滞 ±0.02：升档需越过边界 0.02，降档需低于边界 0.02。

档位下限，只抬不降，不改 IN 数值：

| 编号 | 条件 | 抬到 |
|---|---|---|
| G1 | `ΣF ≥ 41` 或 `SS_sub ≤ 2` | L1 |
| G2 | `ΣD ≥ 24` | L2 |
| G3 | `ΣD ≥ 31` | L3 |
| G4 | `ΣA ≥ 19` | L2 |

## 8. 适用范围

1. 主观支持是间接通路。即使把 `SS_sub` 从最低推到最高，也只能改善一部分，因此不应把目标定在完全改善用户的负面状态。
2. 不替代诊断。24 维分数是对话内的隐式估计，不是量表施测结果。
