# 03 · 查档表

用于不现场演算的情况。主路径仍是 `02-math-model.md` 的公式。表由 `scripts/build_lookup.py` 从同一份实现生成，与公式的差别只有分箱带来的量化误差：最多差一档，不会差两档（随机抽取 4000 个状态实测，一致率 62.2%）。

---

## 用法（三步）

1. 把 `ΣD`、`ΣA` 换成档位 → 查第一张表得到**症状档 S**。
2. 把 `ΣF` 换成**倦怠档 F**，`SS_sub` 换成**支持档 SS**（支持分越高，档位越高）。
3. 查对应的 F 表：行是 S 档，列是 SS 档，交叉点就是档位。

如果算出来的档位和表里差了两档以上，说明公式算错了，重算。

## 查出档位之后：加护栏，再取高

表格只给**纯分数档**。四条护栏必须手动叠上去（它们来自临床阈值，不在表里）：

| 编号 | 条件 | 抬到 |
|---|---|---|
| G1 | `ΣF ≥ 41` 或 `SS_sub ≤ 2` | 至少 L1 |
| G2 | `ΣD ≥ 24` | 至少 L2 |
| G3 | `ΣD ≥ 31` | 至少 L3 |
| G4 | `ΣA ≥ 19` | 至少 L2 |

```
最终档 = max(表里的档, 命中的护栏档)
自杀自伤 = 5 或本轮出现明确实施意图 → L4（忽略以上全部）；3 分与 4 分按 L3 处理
```

## 不适用的场合

- 需要精确 IN 数值时（例如记录趋势曲线），用公式或 `scripts/in_score.py`。
- 分数正好卡在档位边界时，用公式，表会把边界抹平。
- 危机判定不看表，只看第九项和明确信号。
