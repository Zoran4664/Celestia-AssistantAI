# SOHO / CCOR 彗星：判断两颗是不是同一颗

## 判据

SOHO / CCOR 视场里的彗星**速度近似**（多为克鲁兹族掠日彗星），因此：
**在相同的时间间隔内，X、Y 方向的移动距离也应接近**。
比较「每单位时间（每小时）的 ΔX、ΔY」是否一致（允许小幅误差，通常 ±10%~20% 内视为一致）。

## 输入格式识别

| 例子 | 解析 |
|---|---|
| `1215 1650 1385` | **时分 = 12:15**，X = 1650，Y = 1385 |
| `CCOR2_1A_20260918T191514_V00_NC_processed.fits: (645, 395)` | 年月日 = **2026-09-18**，时分秒 `191514` 里只取**时分 = 19:15**，X = 645，Y = 395 |
| `18:15:25 689 345` | 时分秒 = 18:15:25（**只比时分 18:15**），X = 689，Y = 345 |
| `20260917 18:15 689 345` | 年月日 = 2026-09-17，时分 = 18:15，X = 689，Y = 345 |

要点：
- 时间**只看时分**（秒忽略）；文件名里的 `T191514` 取 `1915`；
- 坐标是 **像素坐标 (X, Y)**，不是赤经赤纬；
- 有时候**不写年月日**（只有 `1215` 或 `18:15`）——这时按下面「判断次数」处理。

## 计算步骤

设两颗目标 A / B：

1. 取 A 的 `(t_A, X_A, Y_A)`、B 的 `(t_B, X_B, Y_B)`（时分换算成小时，例如 19:15 → 19.25）。
2. 时间差 `Δt = t_B − t_A`（小时；跨日时按下面三种情形处理）。
3. 位移 `ΔX = X_B − X_A`、`ΔY = Y_B − Y_A`。
4. 速度 `vX = ΔX / Δt`、`vY = ΔY / Δt`。
5. 判断：A 的速度特征（同一家族典型速度）与 B 的 `(vX, vY)` 是否一致 → 一致即**同一颗**。

## 判断次数（重要）

- **所有目标都给了年月日** → 只判断一次：**同一天**是不是同一颗；
- **只要有任何一颗没给年月日** → 必须输出**三次判断**：
  1. 同一天的情况下，是不是同一颗；
  2. A 在前一天、B 在后一天，是不是同一颗；
  3. B 在前一天、A 在后一天，是不是同一颗。

## 输出格式（每次判断都给）

```
判断 N：<情形说明>
  时间差 Δt = X 小时（A 19:15 → B 20:15）
  位移 ΔX = +NNN px，ΔY = +NNN px
  速度 vX = NN px/h，vY = NN px/h
  结论：是 / 不是 / 无法判断 + 依据一句话
```

- 数据不足（缺坐标或缺时间）→ 明确写「无法判断，缺 XX」，**不要**硬凑结论。
